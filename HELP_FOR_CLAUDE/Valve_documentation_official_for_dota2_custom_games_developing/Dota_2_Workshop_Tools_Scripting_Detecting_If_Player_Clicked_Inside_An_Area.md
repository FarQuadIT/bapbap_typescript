It should cover the area you want to be tested. - Step 2: Select the brush you just and go to Tools > Tie To Entity (Ctrl+T). This will create a trigger entity that is tied to your box. - Step 3: Select the trigger and change its class to "trigger_multiple". - Step 4: Give the trigger a targetname, for the sake of this example, let's call it "trigger_no_ward".
