### 1. Код:
- **Язык:** Это не код в традиционном смысле, а конфигурационный файл в формате Key-Value, часто используемый в играх.
- **Видимый код:**

```plaintext
"Version" "1"
"ecchens_armor"
{
    "BaseClass" "ability_lua"
    "ScriptFile" "abilities/ecchens_armor"
    "AbilityBehavior" "DOTA_ABILITY_BEHAVIOR_PASSIVE"
    "AbilityValues"
    {
        "bonus_armor" "5 10 15 20"
    }
}
"ursa_copy"
{
    "BaseClass" "ability_lua"
    "ScriptFile" "abilities/ursa_copy"
    "AbilityBehavior" "DOTA_ABILITY_BEHAVIOR_PASSIVE"
    "AbilityValues"
    {
    }
}
```

- **Описание:**
  - **"Version" "1"**: Указывает версию файла.
  - **"ecchens_armor"** и **"ursa_copy"**: Это определения способностей.
  - **"BaseClass"**: Указывает базовый класс способности, в данном случае `ability_lua`.
  - **"ScriptFile"**: Указывает путь к Lua-скрипту, который реализует логику способности.
  - **"AbilityBehavior"**: Определяет поведение способности, здесь это пассивная способность.
  - **"AbilityValues"**: Содержит параметры способности, такие как бонус к броне.
