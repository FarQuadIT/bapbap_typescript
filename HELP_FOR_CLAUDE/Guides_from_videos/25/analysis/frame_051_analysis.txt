### Видимый код:
```lua
require("tables/item_drop")

if ItemDropManager == nil then
    ItemDropManager = class({})
end

function ItemDropManager:Init()
    ListenToGameEvent("entity_killed", Dynamic_Wrap(self, 'EntityKilled'), self)
end

function ItemDropManager:EntityKilled(event)
    local killedUnit = EntIndexToHScript(event.entindex_killed)

    local items = ITEM_DROP[killedUnit:GetUnitName()]

    if not items then return end

    local randomNumber = RandomFloat(0, 0.99)
    local cumulativeProbability = 0
    local dropItem = nil

    for _, item in ipairs(items) do
        cumulativeProbability = cumulativeProbability + item.chance
        if randomNumber < cumulativeProbability then
            dropItem = item
            break
        end
    end

    if not dropItem then return end

    local newItem = CreateItem(dropItem.item, nil, nil)
    CreateItemPositionForLaunch(killedUnit:GetAbsOrigin(), newItem)
    newItem:LaunchLootInitialHeight(false, 0)
end
```

### Описание кода:
- **Импорт**: Подключается модуль `tables/item_drop`.
- **Класс `ItemDropManager`**: Создается класс для управления выпадением предметов.
- **Метод `Init`**: Инициализирует прослушивание события `entity_killed`.
- **Метод `EntityKilled`**: Обрабатывает событие убийства сущности:
  - Получает убитую сущность.
  - Извлекает список предметов, которые могут выпасть.
  - Генерирует случайное число и определяет, какой предмет выпадет на основе вероятности.
  - Создает и позиционирует новый предмет, устанавливая начальную высоту его полета.

### Важные детали:
- **Переменные**: `killedUnit`, `items`, `randomNumber`, `cumulativeProbability`, `dropItem`, `newItem`.
- **Функции**: `CreateItem`, `CreateItemPositionForLaunch`, `LaunchLootInitialHeight`.
