### Видимый код:

```lua
function modifier_gold_hole_thinker:OnCreated()
    local radius = self:GetAbility():GetSpecialValueFor("radius")
    if not IsServer() then return end

    self._effect_cast = ParticleManager:CreateParticle("particles/econ/items/riki/riki_head_ti8_gold/riki_smokebomb_ti8_gold.vpcf", PATTACH_WORLDORIGIN, nil)
    ParticleManager:SetParticleControl(self._effect_cast, 0, self:GetParent():GetOrigin())
    ParticleManager:SetParticleControl(self._effect_cast, 1, Vector(radius, radius, radius))

    self:StartIntervalThink(1)
end

function modifier_gold_hole_thinker:OnDestroy()
    ParticleManager:DestroyParticle(self._effect_cast, false)
end

function modifier_gold_hole_thinker:OnIntervalThink()
    local caster = self:GetCaster()
    local parent = self:GetParent()
    local radius = self:GetAbility():GetSpecialValueFor("radius")
    local gold_per_unit = self:GetAbility():GetSpecialValueFor("gold_per_unit")

    local enemies = FindUnitsInRadius(caster:GetTeamNumber(), parent:GetAbsOrigin(), nil, radius, DOTA_UNIT_TARGET_TEAM_ENEMY, DOTA_UNIT_TARGET_HERO + DOTA_UNIT_TARGET_BASIC, DOTA_UNIT_TARGET_FLAG_NONE, FIND_ANY_ORDER, false)
    local gold = gold_per_unit * #enemies

    caster:ModifyGold(gold, true, 13)
    EmitSoundOnClient("General.Coins", caster)
    SendOverheadEventMessage(caster:GetPlayerOwner(), OVERHEAD_ALERT_GOLD, caster, gold, caster)
end
```

### Описание кода:

1. **Функция `OnCreated`:**
   - Инициализирует радиус действия эффекта, используя специальное значение способности.
   - Создает партикл-эффект в мире игры.
   - Устанавливает контрольные точки для партикла, чтобы задать его позицию и размер.
   - Запускает периодическое выполнение функции `OnIntervalThink`.

2. **Функция `OnDestroy`:**
   - Уничтожает созданный партикл-эффект при удалении модификатора.

3. **Функция `OnIntervalThink`:**
   - Определяет кастера и родителя модификатора.
   - Вычисляет количество золота, которое будет добавлено кастеру, на основе количества врагов в радиусе.
   - Добавляет золото кастеру и воспроизводит звуковой эффект.
   - Отправляет сообщение о получении золота.
